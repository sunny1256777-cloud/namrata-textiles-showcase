# 🥻 Namrata Textiles — Luxury 3D Immersive Digital Showroom

> 🚀 **Live Demo:** [Open Namrata Textiles 3D Experience](https://namrata-textiles.vercel.app)

An experiential, cinematic WebGL web application for **Namrata Textiles**, designed to recreate the feeling of walking inside a ₹5 Crore haute couture textile palace. Built with real-time cloth physics, custom silk shaders, and procedural soundscapes.

---

### ✨ Key Experience & Modules

- **3D WebGL Procedural Silk Canvas:** Three.js custom vertex & fragment shaders simulating real-time cloth ripples, lighting Fresnel sheen, 650+ floating golden dust particles, and entrance stage curtain reveals.
- **Interactive Web Audio Soundscape:** Ambient D-major drone pad and 523Hz royal chimes generated directly via the Web Audio API without external audio files.
- **Hover-Reactive Showroom:** Dynamic shader tint shifts (Burgundy, Champagne Gold, Obsidian) synchronized with product card interactions.
- **360° Interactive Fabric Inspector:** Real-time 3D swatch viewer with rotation, drape frequency controls, zoom, and sheen presets (*Mulberry Silk, Regal Velvet, 24k Zari Metallic, Organza Sheer*).
- **9 Curated Scroll-Story Scenes:** Spline-path camera transitions flying through Royal Entrance, Golden Atrium, Saree Vault, Bridal Lehengas, Groom Suites, and Artisanal Legacy.
- **Editorial Magazine Lookbook:** High-fashion fullscreen editorial spread with smooth page-flip interactions.
- **VIP Consultation Booking:** Direct WhatsApp concierge integration and bespoke appointment scheduling.

---

### 🛠️ Tech Stack & Architecture

- **Frontend Framework:** React 19, TypeScript
- **3D & Graphics Engine:** Three.js, WebGL Custom GLSL Shaders (Vertex & Fragment)
- **Audio Architecture:** Web Audio API Procedural Synthesizer
- **Styling & Theme:** Tailwind CSS (*Obsidian Black `#050505`, Royal Gold `#D4AF37`, Cream White*)
- **Typography:** Cormorant Garamond, Playfair Display, Inter
- **Icons & Modals:** Lucide React
